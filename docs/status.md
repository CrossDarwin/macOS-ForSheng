# sheng 移植状态

本页记录 macOS 26.5 / 25F71 在 sheng（SM8550）上的验证结果，更新于 2026-10-26。
内核为配套 XNU 12377.121.6 ARM64E。当前目标是在实机显示原版 Recovery 语言选择器。

## 已验证结果

| 项目 | QEMU | sheng 实机 |
| --- | --- | --- |
| 内核与用户空间 | 原版 dyld、launchd 及恢复服务已执行 | 原版 launchd 及恢复服务已执行 |
| 根卷与辅助卷 | BaseSystem、ISC 角色卷和临时 Data 卷已挂载 | UFS 读取、BaseSystem 和 ISC 挂载已通过 |
| 显示 | 原版语言选择器已显示，真实输入选中简体中文 | GOP 开屏事件已到达，尚无本轮首帧复制证据 |
| Recovery 后续界面 | 选择语言后 Recovery Springboard 进程已出现，工具窗口未验收 | 语言选择器未显示 |
| 持久日志 | 双槽提交、CRC 和保护范围验证通过 | macoslog 双槽读回通过，最终 panic 未保存 |
| 输入与图形加速 | VirtIO HID 可用；画面由 CPU 复制 | 触控、USB 输入和 Adreno 加速未验收 |

QEMU 语言选择器证据来自构建 40305570169，不套用到之后的内核。
构建 40319163123 在 QEMU 完成首次帧复制，停止时是黑底等待指针；本版没有重复语言选择器验收。

## 本轮实机结果

候选 `0CF06C86-6A75-3360-99B8-1B1ADFB87ECD` 来自构建 40319163123。
临时启动复用了已验证的固件容器、设备树和已安装根卷，启用 UFS、ISC、GOP、日志和启动进度诊断。

屏幕先到达 `Recovery exec`，随后到达 `Display on`。
WindowServer 格子仍为 `-`，只说明该事件没有被诊断器记录，不能据此断言进程没有执行。
最后出现：

```text
phystokv_range: illegal PA: 0x169b0000
phys base 0x8c1004000, size 0xc0000000
@arm_vm_init.c:418
```

Recovery 只读导出的两个快照代数为 105、106，均与候选 UUID 匹配。
最新快照保留 80,037 字节，无环形覆盖遗漏，记录 3,537 字节 writer 忙时丢失。
文件外区域、FAT 和保护块与预分配镜像一致。快照结束于服务注册日志，没有包含最终 panic。
照片、视频、分区镜像和解码记录只保存在本地 `private/`。

## 当前修正与待验证项

配套源码的 `pmap_sync_page_attributes_phys()` 先对 32 位页号移位，再转换地址类型，会丢失高位。
对物理地址 `0x9169b0000` 使用原表达式会得到本次 panic 中的 `0x169b0000`。
已接入 UniXNU 的 `zzx-pmap-sync-64bit-pa.patch`，在移位前扩展地址宽度；构建 40324187134 已通过。
现场没有完整回溯，因此这属于与错误地址吻合的原因，尚待实机确认。

首次 panic 的[离线二维码](panic-qr.md)已实现。
独立 ARM64 执行测试已从实际帧缓冲像素解码出匹配的消息；包含该实现的完整内核、UFS、GOP 和输入组件构建 [40326900585](https://github.com/CrossDarwin/macOS-ForSheng/actions/runs/40326900585) 已通过；实机扫码尚未验收。
二维码保留有界摘要，不替代完整日志或调用栈。

下一次候选为 `2DDC876A-3B4C-3478-8B21-556B7E879EB0`，菜单为 `UFS+ISC+LOG+UI+QR 2DDC876A`。
产物反汇编已确认使用 64 位地址移位。候选已封装，尚未实机执行。
本轮复用已有固件、设备树和根卷，没有重复完整 QEMU 用户态或语言选择器验收。
实测继续验证高位地址修正后是否越过开屏阶段。
若再次 panic，读取屏幕文字及二维码，并导出已提交的日志槽。
本轮不以恢复工具窗口、触控或 GPU 加速作为临时启动条件。

## 尚未支持

- sheng 原生图形 Recovery、触控和 USB HID 输入尚未验收。
- Adreno 740 的 macOS 加速驱动尚未实现。
- KDP 的实机双向轮询传输尚未接通。
- 完整运行历史、最终 panic 落盘及跨重启 RAM 保留没有保证。
- Apple 激活、系统安装和日常桌面使用未验收。
